# SAFA Phase 5 — Design System Component Usage Matrix

## Design System Component Utilization Matrix

| Shared Component | Purpose / Design Tokens | Usage across Screens | Audit Status |
| --- | --- | --- | --- |
| `AppCard` | Standard surface card with border & corner radius | Dashboard, Customers, Suppliers, Wallet, Expenses, Settings | **PASS** |
| `AppStatusChip` | Semantic status badges (Pending, Synced, Failed) | Transactions, Customer Profile, Sync UX | **PASS** |
| `AppMetricCard` | Financial balance & summary metrics | Dashboard, Customer Profile, Supplier Summary | **PASS** |
| `AppSectionHeader` | Standard section title + action | Dashboard, Reports, Customer List, Supplier List | **PASS** |
| `AppPrimaryButton` | Standard 48dp height primary CTA | Login, Add Customer, Create Remittance, Save Settings | **PASS** |
| `AppOutlinedButton` | Standard 48dp height secondary CTA | Cancel actions, Filter dialogs, Export reports | **PASS** |
| `AppTextField` | Outlined input field with label & error support | Login, Form fields, Customer search, Deduct funds | **PASS** |
| `SafaConfirmDialog` | Standard confirmation dialog | Transaction status change, Settings update | **PASS** |
| `SafaDestructiveDialog` | Standard destructive confirmation dialog | Delete Customer, Delete Supplier, Delete Transaction, Master Reset | **PASS** |
